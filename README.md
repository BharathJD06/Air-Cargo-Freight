## 📌 Project Overview
A comprehensive analysis of air cargo freight data examining shipment volumes, routes, carrier performance, and cost efficiency. The project identifies key operational patterns and provides data-driven recommendations for logistics optimization.

## 🗂️ Files
| File | Description |
|------|-------------|
| Air Cargo Freight.ipynb | Python analysis notebook |
| cargo_fright.csv | Raw cargo freight dataset |
| Air Cargo Freight Report.pdf | Full analysis report |

## 🛠️ Tools & Technologies
- **Python** (Pandas, NumPy, Matplotlib, Seaborn) — Data analysis & visualization
- **Jupyter Notebook** — Development environment

## 📊 Key Analysis
- Shipment volume trends and seasonal patterns
- Route performance & carrier efficiency comparison
- Cost analysis per unit weight/distance
- Data cleaning & outlier detection
- Freight demand forecasting

## 💡 Key Insights
- Identified high-demand routes with optimization potential
- Uncovered cost inefficiencies in specific freight corridors
- Seasonal demand patterns for strategic capacity planning
